# mcp-1c-syntax-assistant

[![tests](https://github.com/IElagin/mcp-1c-syntax-assistant/actions/workflows/ci.yml/badge.svg)](https://github.com/IElagin/mcp-1c-syntax-assistant/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

[English](README.md)

MCP-сервер, который даёт ИИ-агентам точные ответы из синтаксис-помощника
1С:Предприятие.

Агент спрашивает элемент по имени и получает карточку фиксированной формы:
строка вызова, параметры с типами и обязательностью, тип возвращаемого
значения, доступность по контекстам исполнения, версия платформы, описание,
пример. Отсутствие данных карточка называет прямо, а не пропускает молча:
пропущенное поле неотличимо от «данных нет», и модель достраивает пробел
домыслом.

## Как выглядит ответ

Реальный вывод `get_1c_element(name="Добавить", object="Массив")`:

```
Массив.Добавить — процедура объекта Массив

Вызов: Массив.Добавить(<Значение>)
Параметры:
    Значение — Произвольный, необязательный
      Добавляемое значение. Если не указан, то будет добавлено значение типа Неопределено.

Возвращает: нет (процедура)
Доступность: тонкий клиент, веб-клиент, мобильный клиент, сервер, толстый клиент, внешнее соединение, мобильное приложение (клиент), мобильное приложение (сервер), мобильный автономный сервер
Доступно с: 8.0

Описание: Добавляет элемент в конец массива.
Примечание: При добавлении количество элементов массива увеличивается на 1.
Пример:
  Массив.Добавить("Первый");
  Массив.Добавить("Второй");
```

## Что нужно

- Docker и Docker Compose v2
- 4 ГБ свободной оперативной памяти (Elasticsearch поднимается с кучей 1 ГБ)
- Файл справки 1С `shcntx_ru.hbk`

> **Файл справки `.hbk` в комплект не входит.** Он проприетарный и
> поставляется с лицензионной установкой 1С:Предприятие — копируйте его
> оттуда. Распространению файл не подлежит.

На Windows файл лежит рядом с исполняемыми файлами платформы:

```
C:\Program Files\1cv8\<версия>\bin\shcntx_ru.hbk
```

Каталог `data/` внесён в `.gitignore`, поэтому файл не попадёт в репозиторий по
неосторожности. Если вы поднимаете сервер для коллег, они получают сервис, а не
файл.

## Быстрый старт

Склонируйте репозиторий и из его корня выполните:

```powershell
# 1. Скопировать книгу справки из своей установки 1С
Copy-Item "C:\Program Files\1cv8\8.3.24.1234\bin\shcntx_ru.hbk" data\hbk\

# 2. Поднять Elasticsearch и MCP-сервер
docker compose up -d

# 3. Посмотреть, как наполняется индекс
Invoke-RestMethod http://localhost:8000/health
```

Индексация запускается сама при первом старте и идёт в фоне. Её ход виден в
`/health`:

```json
{"status":"healthy","elasticsearch":true,"index_exists":true,
 "documents_count":23125,"indexing_status":"idle","indexing_active":false,
 "index_en_exists":true,"documents_count_en":23104,"version":"2.0.0"}
```

Сервер готов, когда `indexing_active` равно `false`, а `documents_count`
перестал расти. `index_en_exists`/`documents_count_en` отслеживают английскую
книгу так же — она необязательна, поэтому оба поля равны `false`/`null`, пока
английская книга не положена рядом с русской и не проиндексирована. Оба
контейнера слушают только `127.0.0.1` — прежде чем открывать что-либо в сеть,
прочитайте [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Дальше — подключить редактор: [docs/CLIENT_SETUP.md](docs/CLIENT_SETUP.md).

## Инструменты MCP

| Инструмент | Назначение |
|---|---|
| `find_1c_help` | Найти кандидатов, когда точное имя неизвестно, — по одной строке на элемент, без полной карточки. |
| `get_1c_element` | Полная карточка элемента с известным точным именем; при неуникальном имени вместо карточки приходит перечень кандидатов. |
| `list_1c_object_members` | Методы, свойства, события и конструкторы одного объекта, по строке на элемент. |

Схемы, лимиты и точное поведение при неоднозначном или отсутствующем имени:
[docs/MCP_TOOLS.md](docs/MCP_TOOLS.md).

## Поддержка языков

Каждый инструмент принимает аргумент `lang` (`"ru"` или `"en"`, умолчание
берётся из переменной окружения `DEFAULT_HELP_LANG`), который задаёт, из какой
книги приходит *ответ* — из русского индекса или из английского, — и тем самым
его язык. Это отдельная ось от того, на каком языке написано переданное имя.

**При умолчании `lang="ru"` находятся имена на обоих языках.** `НайтиСтроки` и
`FindRows` приводят к одному элементу, `Добавить` и `Add` — тоже: русская
книга справки несёт оба имени в заголовке каждой страницы элемента
(`<h1>НайтиСтроки (FindRows)</h1>`), и индексатор расщепляет их в поля
`name_ru` и `name_en`. Все 20 159 страниц элементов в текущем индексе несут
английское имя. Имена объектов находятся тоже: `list_1c_object_members(
object="ValueTable")` и `get_1c_element(name="Add", object="Array")` работают,
хотя у страниц объектов, в отличие от страниц элементов, английского имени в
собственном заголовке нет — сервер достраивает его из необязательного
английского индекса (см. ниже) в соответствующую русскую страницу объекта
после индексации. Из 2 577 страниц объектов так получили английское имя 2 326
(около 90%), и все 389 страниц конструкторов — тоже; 251 объект остаётся
доступен только по русскому имени. В любом случае сама карточка — описание,
параметры, доступность, пример — русская, потому что на другом языке русская
книга их не несёт.

**`lang="en"` — другое: полностью английский ответ**, из необязательной
второй книги (`shcntx_root.hbk` — см.
[docs/CONFIGURATION.md](docs/CONFIGURATION.md#английская-книга-справки)), а не
перевод русского. Он требует, чтобы эта книга была проиндексирована, и требует
английское имя — русское имя отклоняется прямо, а не ищется молча в русском
индексе под видом английского ответа (см. ниже). Реальный вывод
`get_1c_element(name="Add", object="Array", lang="en")` по текущему
английскому индексу (23 104 документа):

```
Array.Add — procedure of Array

Call: Array.Add(<Value>)
Parameters:
    Value — Arbitrary, optional
      Added value. If not specified, a value of Undefined type will be added.

Returns: nothing (procedure)
Availability: thin client, web-client, mobile client, server, thick client, external connection, mobile application (client), mobile application (server), mobile standalone server
Available since: 8.0

Description: Adds an element to the end of the array.
Note: When an element is added, the number of elements in the array is increased by 1.
Example:
  Array.Add("First");
  Array.Add("Second");
```

Запрос, смешивающий языки неверно, — кириллическое имя с `lang="en"`, либо
любой вызов `lang="en"` до того, как английская книга проиндексирована, —
получает объяснённый отказ вместо молчаливого пустого ответа. В обратную
сторону так не бывает: `lang="ru"` свободно принимает английское имя, потому
что русская книга несёт оба. Точный текст всех трёх случаев отказа:
[docs/MCP_TOOLS.md](docs/MCP_TOOLS.md#кросс-языковые-запросы).

## Отличия от базового проекта

За основу взят [Antonio1C/1c-syntax-helper-mcp](https://github.com/Antonio1C/1c-syntax-helper-mcp)
(MIT — так объявлено в его README): от него — структура FastAPI-сервиса, разбор
`.hbk` через 7-Zip и индексация в Elasticsearch. Что изменилось:

- **Карточка элемента — контракт, а не свободный текст.** Набор полей
  печатается всегда, а отсутствие данных помечается («Доступность: в справке не
  указана», «Примеров в справке нет»), а не выбрасывается из ответа.
- **Три инструмента MCP вместо одного**, у каждого явная JSON-схема: агент
  выбирает инструмент по назначению, а не угадывает аргументы.
- **Дизамбигуация вместо молчаливого выбора.** Имя `Добавить` встречается на 197
  страницах; сервер возвращает упорядоченный перечень кандидатов и просит
  уточнить объект, а не выдаёт произвольный из них за ответ.
- **Варианты вызова, настоящая обязательность параметров и тип значения
  свойства** разбираются из HTML справки.
- **Воспроизводимый замер качества поиска** — `scripts/eval_search.py` строит
  эталон из самого индекса и считает долю попаданий.

Полная атрибуция и перечень изменений: [NOTICE](NOTICE).
